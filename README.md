# 🧠 DeepSeek Code Companion

**DeepSeek Code Companion** is your AI-powered coding assistant built using Streamlit, LangChain, and Ollama. It helps developers debug code, generate solutions, and understand code snippets — all in a natural chat interface. Just ask your coding questions and let DeepSeek assist you!

---

## 🚀 Features

- ✅ **AI Pair Programmer** using open-source models (DeepSeek, LLaMA2, LLaMA3, Mistral)
- 🐞 **Code Debugging Assistant** with smart print statements
- 🧠 **System-Prompted AI Context** for smarter answers
- 🎨 **Dark UI Theme** with responsive sidebar controls
- 💬 **Interactive Chat History** using Streamlit session state
- 🔗 Built on [Ollama](https://ollama.ai), [LangChain](https://python.langchain.com/), and [Streamlit](https://streamlit.io/)

---

## 🛠 Tech Stack

| Layer         | Tool/Framework              |
|---------------|-----------------------------|
| 🧠 AI Models   | DeepSeek, LLaMA2, LLaMA3, Mistral |
| 🤖 LLM Wrapper | LangChain (`langchain_ollama`) |
| ⚙️ Backend     | Python, Ollama (localhost)  |
| 🖥️ Frontend    | Streamlit (dark themed)     |
